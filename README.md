# 项目名称
雨课堂课程自动播放脚本

## 运行方法

确保电脑安装 python 运行环境，推荐在 python venv 虚拟环境中运行。

运行后，浏览器会直接进入雨课堂登录页面，扫码登录即可。
登录仅需首次进入登录一次，程序会自动保存网页当前状态，以后使用，每次进入都会是您的课程主页。如遇账号偶然退出，只需重新扫码登入即可。

进入课程页面后，您只需点击您需要观看的网课课程，后续程序会全自动执行观看和切换任务，您只需保证页面一直在运行，不要乱动即可。

测试过程中发现有偶发性暂停，如果您也遇到课程暂停的情况，不用担心，刷新网页或者退出程序重新进入都可以解决。

**其他说明：**  
程序进入后会自动 2 倍速，静音播放，这是程序默认行为。新视频开始播放时，会有漏音现象，您不用担心，推测可能是静音设置时效性问题，目前无法有效解决。**您可以关闭电脑音量或者减小音量以缓解漏音问题。**

（本项目由 chatGPT 辅助开发完成）
